세션 관리

로컬|원격 듀얼 패널 · 창을 닫아도 이어지는 백그라운드 전송 · 전체 진행률 · 폴더 트리에서 바로 업/다운로드

설치 방법

위의 다운로드 버튼으로 설치 파일(SSHTool2_x64-setup.exe)을 받습니다.
받은 파일을 실행하고 설치를 진행합니다.
설치 위치 등은 기본값 그대로 두면 됩니다. 몇 초면 끝납니다.
실행 후 ＋ 새 세션으로 서버를 등록하거나, 빈 곳을 우클릭해 다른 클라이언트에서 가져오기로 기존 설정을 옮깁니다.
Windows SmartScreen 안내 — 서명되지 않은 설치 파일이라 처음 실행 시 파란 경고창이 뜰 수 있습니다. 「추가 정보」 → 「실행」을 누르면 설치됩니다. 설치 후 업데이트는 앱 안에서 자동으로 이뤄집니다.
