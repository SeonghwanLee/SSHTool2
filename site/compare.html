SSHTool2 에만 있는 것

네 제품의 공식 기능 목록에는 없고 SSHTool2 에는 있는 것들입니다.

  • 외부 프로그램 세션 가져오기
    PuTTY · SecureCRT · MobaXterm · WinSCP · FileZilla 5종의 저장된 세션을 폴더 구조까지 그대로 가져옵니다.
  • 세션 색 태그
    운영과 개발을 색으로 구분해 목록과 탭에 띠로 표시합니다.
  • 자동 재접속
    예기치 않게 끊기면 정해진 간격 · 횟수만큼 스스로 다시 붙습니다(직접 끊은 경우는 제외).
  • 세션 빠른 찾기(Ctrl+P)
    이름 · 계정@호스트 · 폴더로 검색해 Enter 로 바로 접속합니다.
  • 내부망 모드
    인터넷이 차단된 환경에서 외부로 나가는 UI와 주소를 감춥니다.
  • 한글 환경 최적화
    IME 조합 표시 · EUC-KR 서버 파일명 · 글자 폭 보정을 전용 테스트로 검증합니다.

이 표를 읽는 법

비교 대상은 오랜 기간 다듬어진 상용 · 대형 오픈소스 제품입니다. 기능 수로 겨루자는 표가 아니라, 무엇을 아직 안 갖췄는지 스스로 확인하려고 만든 표입니다. 표시가 X 인 항목은 그대로 개발 목록에 올라 있습니다.

출처와 한계 — 판정은 각 제품이 공식적으로 밝힌 기능 목록을 기준으로 했습니다. 실제 제품에는 목록에 적히지 않은 기능이 더 있을 수 있고, 같은 이름의 기능이라도 깊이가 다를 수 있습니다. 특히 FileZilla 는 공식 기능 페이지에 접근하지 못해(HTTP 403) 프로젝트 사이트와 공개 문서로 대신했으므로, 그 열은 다른 셋보다 근거가 약합니다.
